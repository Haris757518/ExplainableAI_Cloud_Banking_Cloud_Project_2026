# Objectives

The primary objectives of this project are to design, develop, and deploy a comprehensive cloud performance monitoring and analytics framework for digital banking. The specific objectives include:

1. **Framework Development**: Develop a scalable AI-driven cloud performance monitoring framework using a modern technology stack (React, FastAPI, Python).
2. **Anomaly Prediction**: Design and train Graph Neural Networks (GNNs) to effectively model resource dependencies and accurately predict performance anomalies in cloud systems.
3. **Explainability**: Integrate Explainable AI (XAI) modules (such as SHAP or similar techniques) to generate transparent and interpretable insights regarding the root cause of detected anomalies.
4. **Resource Optimization**: Improve overall cloud resource utilization, scalability, and efficiency by proactively identifying bottlenecks.
5. **Interactive Visualization**: Create an intuitive, real-time frontend dashboard for cloud administrators to visualize performance metrics, prediction alerts, and XAI insights.
6. **Cloud Deployment**: Successfully deploy the architecture on AWS, utilizing services like EC2, S3, SageMaker, Lambda, and CloudWatch to ensure high availability and security.
