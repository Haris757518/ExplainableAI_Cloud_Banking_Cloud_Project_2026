# Abstract

Digital banking services depend on distributed cloud infrastructure whose performance can degrade through resource saturation, database latency, network issues and cascading service effects. This project implements an explainable graph-based analytics framework that uses AWS/CloudWatch telemetry, a banking-infrastructure dependency graph and a baseline Graph Convolutional Network to detect and localize performance anomalies. A root-cause analysis layer ranks probable causes using graph and telemetry evidence, while an explanation layer highlights influential telemetry dimensions. The project also introduces a Transaction-Conditioned Causal-Frontier Adaptive Observability policy that focuses higher-resolution monitoring on the suspected causal frontier. The implementation uses synthetic telemetry for reproducible development and supports AWS telemetry collection through boto3.
