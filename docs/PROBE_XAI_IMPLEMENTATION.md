# Progressive banking investigation

PROBE-XAI is an experimental evidence-selection and abstention policy. It is not established as a novel or superior method by implementation alone.

## What is implemented

The application opens Banking Cloud and has exactly two primary modes: Banking Cloud and Research & Validation. The live cloud overview does not substitute public bank statistics, external faults or locally generated values for missing Bank of Anthos telemetry. Unknown health numbers remain unknown.

Recorded RE2 investigations use the available compatible per-recording GNN to rank resources. They show the affected measurements, likely location, immediate bottleneck hypothesis, competing deeper drivers, operator-reviewed recommendations and recovery status. Simple explanation is the default. All evidence exposes measured values, original metric names, references and the actual follow-up selection log. JSON is not the investigation interface.

## Evidence policy

The initial common screen covers latency, processing time, CPU and query time where measured. The progressive policy selects another actually available series using the number of unresolved explanations it can distinguish divided by its declared inspection cost. It stops at the budget or when no discriminating series is available. These are transparent coverage heuristics, not learned information gain, live API cost or measured AWS savings.

Demand, expensive execution, reduced capacity, retry amplification, GC and blocking transactions have separate prerequisite signatures. A driver must match its complete measured signature and tested alternatives must be unsupported before the deepest level becomes driver. For example, high CPU alone does not justify scaling. Demand-driven capacity saturation requires measured arrivals above measured capacity, queue growth, CPU pressure, stable workers, stable per-request CPU and stable retries, with demand onset no later than CPU and queue onset. Missing alternatives cause abstention rather than a fabricated deep explanation.

No case name, root-service label or injection annotation is used by PROBE-XAI. Prefix filtering happens before evidence summaries. Compatible GNN inference checks source and trace checksums, requires a post-validation observation time and uses only earlier measured points. Alibaba weights are never applied to banking or RE2.

Recommendations do not execute changes. Recovery requires a separately approved executed intervention, at least three later performance measurements and later checks for consistent pending payments, no duplicate processing and ledger reconciliation. Performance improvement alone is insufficient.

## Research boundaries

The comparison includes statistical localization, GNN-only ranking, GNN plus conventional measured-column inspection and GNN plus progressive inspection. Predictions precede evaluation-only annotation reads. The original five-case compatibility study remains immutable. An additional prespecified RE2 subset is imported separately without replacing earlier evidence.

RCAEval infrastructure-injection categories are not independently labelled explanations of traffic, retry or application drivers. Consequently driver accuracy and unsupported-diagnosis rate are unavailable; abstention and required-evidence audits are reported separately. Local unit-test fixtures are never exported as recorded workload data or counted as experimental success.

## Deployment boundary

The official Bank of Anthos source is pinned in vendor/bank-of-anthos. The prepared manifest bundle disables public load balancers and GCP-specific identity/exporter assumptions. It has not run. Provider-neutral instrumentation, JWT secrets and runtime verification remain required.

Read-only AWS discovery returned EKS AccessDeniedException and EC2 UnauthorizedOperation. Existing S3 and importer-health receipts remain valid for their previous storage execution but do not establish banking compute monitoring. The user approved no new paid resources, a ₹0 incremental cloud budget and zero runtime for new AWS compute. No compute, database, network or new monitoring resources were created for this redesign.
